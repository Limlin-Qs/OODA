# ADR-0002 产品方向记录（已迁移至 PRD）

## 状态（Status）

Deprecated（2026-09-12）。保留编号和文件以保存文档沿革；不再作为架构实现依据。

## 背景（Context）

本记录曾把三类内容混在一起：产品方向与首版范围、业务不变量、尚未形成选择的技术问题。产品范围属于 PRD，问题清单不是架构决策；继续将其标为 Accepted 容易让人误以为后端、数据库、鉴权、通知和部署方案已经获准。

## 处理决定（Decision）

- 产品定位、首版范围、角色和待确认业务问题迁移并维护在 [PRD](../PRD.md)。
- 服务端权威状态与事务一致性边界作为独立且长期的架构提案记录在 [ADR-0003](0003-server-authoritative-transaction-boundary.md)。
- 后端运行时、数据库/ORM、身份模型、通知渠道、部署平台和测试工具在形成真实选择前不建立占位 ADR。
- 本文件不删除，避免编号重用或历史链接失效。

## 后果（Consequences）

- “创新工作室物资共享系统”这一已确认产品方向没有被撤销，只是由 PRD 负责记录。
- 本 ADR 不授权任何技术实现。
- ADR 索引能够区分已接受架构、待确认提案和产品需求。
