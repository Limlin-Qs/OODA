# ADR-0007 站内提醒与可靠任务处理

## 状态

Accepted（2026-09-14）。尚未实现。

## 背景

逾期提醒必须可追踪、可重试且去重；外部通知服务不可用时不能回滚已成立的借用事实。首版还没有外部渠道授权。

## 决策

- 首版只提供站内提醒，不接入邮件、企业微信或飞书。
- 借用事务提交时或提交后创建可追踪的提醒意图；提醒处理在领域事务之外执行。
- 以借用记录和提醒阶段建立唯一去重标识；重复调度不得产生重复提醒。
- worker 失败保留可重试状态和结果；提醒失败不回滚借用或归还事实。
- 具体 worker 进程形态可在 G-009 中选择单独 worker 或受锁保护的应用任务，但必须使用持久化状态。

## 替代方案

- 直接发送邮件或企业通讯：需要外部权限、凭据和失败语义，推迟。
- 仅由前端定时检查：不可靠且不能作为权威调度，拒绝。
- 在借还事务内等待外部发送成功：会把外部可用性引入核心事务，拒绝。

## 后果

首版没有外部凭据依赖，失败可在系统内观察和重试；需要增加站内通知数据和后台处理能力。

## 当前实现与差距

当前没有通知表、提醒页面、worker 或调度机制。

## 不在范围

不实现外部消息渠道、静默时段、升级通知或消息系统。

## 复核条件

用户需要跨系统提醒或站内提醒不足以满足业务时重新评估渠道与凭据边界。
